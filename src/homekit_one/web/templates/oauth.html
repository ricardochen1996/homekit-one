小米 OAuth 授权

  1. 打开授权页用小米账号登录，支持两步验证
  2. 复制回调地址授权后浏览器跳转的页面可能打不开，这是正常的
  3. 粘贴回来网关会换取并保存 token

授权页显示的应用名可能是 “Xiaomi Home (Home Assistant Integration)”，这是复用公开 client id 的正常现象。 token 只保存在本机 secrets.json（0600）。

打开小米授权页

如果按钮没有反应，把下面的地址复制到浏览器：

{{ auth_url }}

粘贴回调地址

授权完成后，浏览器会跳转到 {{ redirect_uri }}。页面打不开没关系； 从地址栏复制完整 URL（含 code=...），或只粘贴 code。

区域 / 回调地址（一般不用改）

默认回调地址是小米为该公开 client 注册的地址， 随意修改可能导致授权页报 redirect_uri 错误。
